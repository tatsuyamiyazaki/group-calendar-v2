# テーマ切替（ダーク／ライト）

## 概要

Group Calendar v2 の UI にダークモードとライトモードの切替機能を追加する。ユーザーは明示的にライト／ダークを選ぶか、OS 設定に追従する `system` モードを選択できる。設定はサーバーに保存され、複数端末で同期する。

## ターゲットユーザー

- 夜間や暗所で利用するユーザー（目の負担を軽減したい）
- OS 全体をダークモードで運用しているユーザー（アプリだけ明るいと違和感がある）
- 明るい環境で利用するユーザー（既存のライト UI を維持したい）

## 機能一覧

| 優先度 | 機能 | 説明 |
|---|---|---|
| 高 | ライト／ダーク／システム の 3 モード切替 | 設定パネルから選択し、即座に UI へ反映する |
| 高 | 設定の永続化（クライアント＋サーバー） | `localStorage` と `APP_SETTINGS_V2.theme` の両方に保存し、端末間で同期する |
| 高 | 全 UI コンポーネントのダークモード対応 | ヘッダー、設定モーダル、予定編集モーダル、カレンダー本体、フォーム |
| 高 | カレンダーイベントの可読性確保 | ダーク背景でもイベントカラーが識別可能で、文字コントラストが基準を満たす |
| 高 | 初期表示時のフラッシュ防止 (FOUC) | React マウント前に `localStorage` から theme を読み、`<html>` クラスを適用する |
| 中 | システムモード時の OS 変更追従 | `prefers-color-scheme` の変化を実行中に検知して切り替える |
| 中 | ヘッダーからのクイックトグル | 設定パネルを開かずに切替できる、月／太陽アイコンのボタン |
| 低 | 既存設定 `useMonoColor` との両立 | モノカラー有効時もダークで視認できる配色を維持 |

## 技術スタック推奨

- **Tailwind CSS**: 既存の CDN 構成を維持し、`darkMode: 'class'` 戦略を CDN コンフィグ (`tailwind.config = { darkMode: 'class' }`) で有効化
- **React Context**: テーマ状態とセッターを SPA 全体に配信
- **永続化**: 既存の `saveSettings` / `loadSettings` を流用しサーバー側に保存。クライアント側初期適用には `localStorage` を併用
- **OS 検知**: `window.matchMedia('(prefers-color-scheme: dark)')`

## 非ゴール

- 任意のカスタムテーマ（ユーザー定義カラーパレット）はスコープ外
- 高コントラストモード／カラーブラインド対応はスコープ外
- iframe 埋め込み環境での親フレーム連動はスコープ外
